# Weekly Meeting Updates

What Sammy brings to the weekly meeting (Friday mornings). Claude keeps it current: block changes as Sammy makes
them, configurator changes as releases go out (Sammy, 2026-11-12).

Each meeting's list has the same three parts:
- **Block Updates:** library blocks added or changed since the last meeting ("None" if none).
- **SWBD Configurator Updates:** by release. First what was released since the last meeting,
  then what's upcoming. A few bullets each, a few words per bullet.
- **Coming Up:** what the releases after that might look like.

Copy the newest meeting into the meeting notes. When a meeting is done, start a new section
above it.
